# AZ-104 Sprint

A one-week study app for the Microsoft AZ-104 (Azure Administrator) exam. It's a single static page with no build step.

- **Today:** readiness score out of 1000 (weighted by exam domain), domain breakdown, 7-day plan
- **Practice:** 76 scenario questions with explanations, domain drills, missed-question review, and a timed 50-question mock exam
- **Flashcards:** about 100 cards with spaced repetition (Space flips a card, 1/2/3 rates it)
- **Cheat sheet:** key limits, SLAs, "which service" tables, az CLI and KQL snippets

Progress is saved in your browser's localStorage. The AI tutor works only in the Claude-hosted version.
